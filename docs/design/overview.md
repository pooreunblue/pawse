# pawse 설계 개요 (초안)

> pawse — 잠시 멈춰 함께했던 순간을 돌아본다.
> 반려동물과 이별했거나 이별을 준비하는 사람을 위한 앱.

상태: **확정** (2026-11-12). 결정 사항은 맨 아래 6절 참고.
관련 문서: [ERD](erd.md) · [API](api.md)

## 1. 구성

| 구분 | 선택 |
| --- | --- |
| 서버 | Spring Boot 4.1.2, Java 21, Gradle |
| DB | PostgreSQL 17 (로컬은 `compose.yaml`, 포트 54321) |
| 클라이언트 | Flutter 모바일 앱 (서버는 화면 없이 REST API만 제공) |
| 패키지 | `org.example.pawse` |

```
Flutter 앱 ──REST──▶ Spring Boot ──▶ PostgreSQL
                        │
                        ├──▶ 파일 저장소 (사진, 생성 이미지)
                        ├──▶ Google Gemini (픽셀 아바타, 하루 메시지 사진 생성)
                        └──▶ Claude API (반려동물 페르소나 챗봇, 메시지 글)
```

패키지는 기능(도메인) 단위로 나눈다.

```
org.example.pawse
├── member      회원, 인증
├── pet         반려동물 프로필, 페르소나 재료
├── album       사진, 타임라인
├── avatar      픽셀 아바타, 의상
├── world       종별 월드, 친구(단짝), 꽃
├── message     하루 메시지, 편지
├── chat        반려동물과의 대화
├── memorial    기념일, 버킷리스트
├── family      가족 공유
└── global      공통 설정, 예외, 파일 저장, AI 클라이언트
```

## 3. 핵심 동작 방식

### 아바타 생성 (F2)

1. 사용자가 앨범 사진 중 기준 사진을 고른다.
2. 서버가 이미지 생성 AI에 "16비트 픽셀 아트" 변환을 요청한다. 오래 걸리므로 비동기로 처리하고 상태(`PENDING → READY / FAILED`)를 둔다.
3. 결과를 **한 번만 생성해 고정 저장**한다. 이후 모든 사진 생성은 이 아바타 이미지를 참조로 넣어 모습을 유지한다.

### 하루 메시지 (F5, F7, F11)

1. 매일 새벽 스케줄러가 메시지 수신이 켜진 반려동물을 순회한다.
2. 활동(놀기·자기·먹기·산책 등)과 혼자/함께를 무작위로 고른다. 함께라면 같은 월드에서 **등장 허용에 동의한** 아바타 하나를 뽑는다.
3. 내 아바타 + 현재 착용 의상 + (친구 아바타)를 참조 이미지로 사진을 생성한다.
4. 전날 편지가 있으면 그 내용에 답하는 글을, 없으면 활동에 맞는 글을 페르소나 말투로 생성한다.
5. 저장 후 푸시 알림을 보낸다. 함께 나온 횟수는 단짝(F16) 집계에 쓴다.

### 대화 (F6, F9)

반려동물 프로필과 습관·성격 기록을 시스템 프롬프트로 조립해 대화 AI를 호출한다. 최근 대화 일부만 문맥으로 넘긴다.

## 4. 반드시 지킬 설계 원칙

- **애도 안전장치**: 메시지 빈도 조절, 쉬어가기, 대화가 AI임을 명시. 심한 우울 신호에는 펫로스 상담 안내.
- **등장 동의**: 다른 사람의 메시지 사진에 내 아바타가 나오는 것은 등록 시 동의한 경우에만.
- **삭제 가능성**: 사용자가 떠날 때 사진·아바타·대화를 모두 지울 수 있어야 한다.
- **비용 통제**: 이미지 생성은 야간 일괄 처리, 사용자당 하루 생성 횟수 제한.

1~6단계가 MVP다. 첫 월드는 강아지 하나로 시작하고, 종 추가는 데이터 한 줄로 가능하게 만든다.
